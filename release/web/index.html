Лимиты Hostkey и источники данных

Hostkey: квоты из рабочих ответов. Остальные источники: чтение страницы использования сервиса без генераций. После 15 минут без наблюдения или наступления срока сброса текущий остаток неизвестен. Другие окна и модели могут отсутствовать.

Тариф и срок подписки получены из записи авторизации; они не подтверждают оплату или автопродление. Ошибка попытки не равна сбою запроса: повтор мог завершиться успешно. HTTP 200 не доказывает получение полного ответа клиентом.

Текущий RPM и занятость по аккаунту не измерены. Они не вычисляются из числа завершённых попыток; отсутствие измерений не означает свободный лимит.
